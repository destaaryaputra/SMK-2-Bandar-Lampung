# SMKN 2 Bandar Lampung School Profile Website

This repository contains a static website that showcases the profile, programs, and gallery of SMKN 2 Bandar Lampung. The project has been reorganized for better maintainability:

- **Folder structure**:
  - `css/` – contains `style.css`.
  - `js/` – contains `script.js`.
  - `assets/images/` – all image assets, renamed to kebab‑case.
- **HTML**:
  - Updated asset paths to reflect the new structure.
  - Added `defer` attribute to the script tag.
- **Future improvements**:
  - Add a favicon.
  - Implement a dark‑mode toggle.
  - Replace JavaScript alerts with inline notifications.

Run the site by opening `index.html` in a browser.
